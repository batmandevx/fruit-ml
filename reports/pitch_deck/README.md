# Pitch deck source

Source of the company pitch deck (20 slides): `deck.json` (order, sections, fonts) and one
HTML file per slide in `slides/`, with speaker notes in each slide's `<aside>`.
The live deck, with PowerPoint/PDF download, is the claude.ai artifact
https://claude.ai/artifact/LPxkjcsX4D8LHfxsLRoodV (private to its owner until shared).

`gradcam_triptych.png` is the image on the explainability slide; the slide references it by
its uploaded asset URL (`/_blob/…`), which only resolves inside the artifact.
