If asked "how do we know it isn't overfitted?": the test sets were never used to make any decision. If asked "what happens when it's unsure?": the confidence is calibrated, and fruits below the review threshold are flagged for a person. For grade that means the system handles 47% of fruit at 97.6% accuracy and passes the rest on.
